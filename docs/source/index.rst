LGBeam Documentation
====================

**LGBeam** is a Python package for generating and analyzing
Laguerre–Gaussian (LG) optical beams.

Features
--------

* Generate Laguerre-Gaussian modes LG(p, l)
* Compute beam parameters:
    * Rayleigh range
    * Beam radius
    * Radius of curvature
    * Gouy phase
* Generate computational meshes
* Plot beam intensity and phase
